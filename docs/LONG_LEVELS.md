# Длинные уровни
Первый мир: каждый маршрут имеет 4 секции, 3 контрольные точки, 3 фрагмента, 90 монет.

Уровень 1: 7900 игровых пикселей (Цветущие луга, Лесная опушка, Старый ручей, Дорога к мосту).
Уровень 2: 8550 игровых пикселей (Речной берег, Деревянные настилы, Водяные колёса, Мельничный двор).

Утверждённый ориентир: обычный уровень 6–8 минут, уровень с мини-боссом 8–10 минут; исследование большинства секретов 10–15 минут. Эти значения требуют реальных замеров.

Уровень 3: 8270 игровых пикселей (Лесные поляны, Пружинящие грибы, Тихая пещера, Тайная тропа).
Уровень 4: 8880 игровых пикселей (Первый пролёт, Механические опоры, Три рычага, Ворота моста). В конце — Страж моста и лавка Моки.

Уровень 5: 9140 px — Часовая улица, Фабричные дворы, Улица посылок, Площадь мастерских. Конвейеры.
Уровень 6: 9910 px — Транспортный тоннель, Пневматические шахты, Зона сортировки, Главный грузовой склад. Паровые подъёмники, конвейеры, мини-босс и магазин Моки.

### Измерение темпа (v0.7)

Игровой HUD теперь отображает активное игровое время уровня и число полученных повреждений. Оба показателя переживают сохранение и загрузку. Для оценки новых целей 6–8 / 8–10 минут необходимы полноценные ручные прохождения; секундомер показывает игровой таймер, а не тестовое время телепортаций Playwright.

Уровень 7: 9470 px; Колокольная улица, Площадь механиков, Архивный проход, Старый регистратор. Часовые пружины без таймера.
Уровень 8: 10180 px; Приёмная склада, Линия сортировки, Комната печатей, Хранилище распоряжений. Мини-босс Патрульный автомат и Моки.
Новая цель 6–8 минут (обычные) и 8–10 минут (с мини-боссом) пока не подтверждена ручным прохождением.

### Протокол проверки темпа (20.10.2026)

Измерять игровой таймер с первого самостоятельного прохождения без тестовых телепортаций. Для каждого уровня сохранять время, число повреждений/попыток, пропущенные фрагменты и долю монет. Проверять отдельно обычный маршрут, маршрут с мини-боссом и исследовательское прохождение. Не вводить таймер как игровое ограничение и не менять каноническую графику персонажей RIKITU. Правки длины и сложности проводить только по этим измерениям.

### Журнал результатов v0.8

После каждого завершённого уровня игра фиксирует активное время, попадания и число собранных монет. Журнал хранится локально и не загружается в GitHub. Для проверки утверждённых целей (6–8 минут обычный и 8–10 минут с мини-боссом) важны наблюдения на обычном управлении; Playwright телепортирует героя и не заменяет такой тест. Игрового тайм-лимита нет.

Уровень 9: 9520 px, Туманная дорога / Скальный уступ / Старая метеостанция / Перевалочный пункт, три мягких воздушных подъёмника.
Уровень 10: 10320 px, Подъём к причалу / Облачные платформы / Зал погрузки / Лётная площадка, Ветряной автомат и лавка Моки.
Цель остаётся 6–8 минут для обычных и 8–10 минут для босс-уровней; подтверждённых замеров ещё нет.
