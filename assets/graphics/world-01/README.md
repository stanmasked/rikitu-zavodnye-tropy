# World 01 — art source policy

The GFX-01 environment drafts and their source manifest are intentionally not stored in this public repository.

Private archive location:
- Google Drive project: **RIKITU — Заводные тропы**
- Folder: **06_Approved_Art_and_Design / GFX-01_Draft_Sources_NOT_APPROVED**
- Private manifest: **RIKITU GFX-01 — Draft Source Archive Manifest and SHA-256**

The archived sources are drafts, not approved final art and not integrated into the game. Do not treat them as canonical character or environment designs. Preserve the exact private archive unchanged and create derived versions for review.

Approved RIKITU character designs are immutable. Import the exact canonical source; do not redraw, replace, reinterpret, or “improve” a selected design.

This public directory contains documentation only. SVG art sources and asset manifests remain in the private Drive archive.
