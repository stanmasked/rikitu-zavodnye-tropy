# RIKITU: Заводные тропы

**Original 2D platformer · GitHub starter v0.1**

Простая приключенческая аркада с лисёнком Рикиту в главной роли.
Это **браузерный прототип всех шестнадцати уровней**, не готовый Nintendo Switch порт.

## Уже реализовано
- Уровень 1 «Цветочная тропа»: монеты, платформы, 3 обязательных фрагмента, выход.
- Уровень 2 «Мельница у ручья»: три фрагмента, механический мини-босс «Заводной Жук».
- Уровень 3 «Грибная роща»: пружинящие грибы, три фрагмента, четыре секции.
- Уровень 4 «Мост шестерён»: рычаги, три фрагмента и мини-босс «Страж моста».
- Уровень 5 «Улица мастерских»: три фрагмента, конвейеры и накладная Корнелиуса Кэша.
- Уровень 6 «Подземная доставка»: три фрагмента, паровые подъёмники, конвейеры, мини-босс «Пыльный бурильщик» и лавка Моки.
- Уровень 7 «Часовая площадь»: мягкие пружинящие циферблаты и улика о времени 07:12.
- Уровень 8 «Склад приказов»: печати, мини-босс «Патрульный автомат» и лавка Моки.
- Три сердца, контрольные точки, прыжок, клавиатура, базовая поддержка gamepad.
- Небольшой игровой тестовый API для воспроизводимых браузерных тестов.

## Запуск без установки

Скачайте `RIKITU_play_now.html`, откройте в современном браузере.
Альтернатива: запускайте `index.html` вместе с `game-core.js`, `game.js` и `style.css`.

**Управление:** ←/→ или A/D — движение, Пробел/↑/W — прыжок,
Shift — ускорение, Enter — начать или далее, P — пауза, R — рестарт.
Для победы над первым мини-боссом трижды прыгните на него сверху.

## Разработка и тесты

Изменять следует `index.html`, `style.css`, `game-core.js`, `game.js`.
После изменения запустите:

```bash
python scripts/build_singlefile.py
node tests/test-core.cjs
python -m pip install playwright==1.57.0
python -m playwright install chromium
python tests/test-browser.py
python tests/test-moki.py
python tests/test-autosave.py
python tests/test-world2.py
```

GitHub Actions проверяет синхронизацию standalone HTML, игровую логику
и браузерные сценарии при обновлении ветки и открытии PR.
Сама CI на GitHub ещё не запускалась до создания репозитория.

## Сюжет и дизайн

См. `GDD.md`. Основное направление согласовано: 4 мира, 16 уровней,
три фрагмента шестерёнки на уровень, мини-босс каждый второй уровень;
расследование остановки Сердца дорог в 07:12.

**Исключительно важное ограничение:** персонажи RIKITU уже утверждены.
Не изменять их лица, силуэты, костюмы и пропорции. Временная буква «Р»
в прототипе — техническая заглушка, а не новый дизайн героя.
Исходные утверждённые арты без отдельного разрешения не публиковать.

## Длина уровней и лавка Моки (v0.2)

Цель — обычные уровни за 6–8 минут и уровни с мини-боссом за 8–10 минут, четыре секции и три контрольные точки на уровень. После мини-босса на каждом чётном уровне открывается лавка Моки RIKITU. Старт: три сердца; максимум: семь. В каждом мире открывается право на одно дополнительное сердечко, а пропущенные покупки не исчезают. Цена четырёх последовательных покупок: 120 / 160 / 200 / 240 монет; суммарно 720. Целевой пул: по 90 монет на каждом из 16 уровней, всего 1440.

В публичном репозитории не размещаем утверждённые рисунки персонажей без отдельного согласования. Технический прототип использует нейтральные маркеры.

## v0.3 — полный технический маршрут первого мира

Четыре удлинённых уровня с 90 монетами и тремя фрагментами каждый. На уровнях 2 и 4 после мини-босса открывается лавка **Моки**. В публичном репозитории Моки обозначен только именем; оригинальный дизайн не перерисовывается. Уровни 5–16 и Switch-порт ещё не готовы.

## v0.4 — проверки магазина Моки и подсказки

После боя в конце каждого второго уровня открывается лавка Моки. Браузерный интеграционный тест теперь проверяет настоящую покупку, баланс кошелька, ограничение 3–7 сердец и перенесённую покупку в лавку после уровня 4. Если игрок приходит к выходу без фрагментов, игра подсказывает название участка, где остался первый несобранный фрагмент. Исходные арты Рикиту и Моки остаются без изменений; используются временные обозначения.


## v0.5 — сохранение прохождения в браузере

Прототип сохраняет собранные монеты/фрагменты, купленные у Моки сердечки, активированные рычаги, контрольную точку и текущее состояние уровня в локальном хранилище браузера. После перезагрузки страницы кнопка Enter продолжает игру с последней контрольной точки (не с произвольной координаты). На экране паузы или кнопкой «Заново» прогресс можно обнулить. Сохранение работает при доступном `localStorage`; если браузер запрещает запись, игра остаётся запускаемой, но прогресс не переживёт обновление страницы. Не отправляем сохранения на сервер.

## v0.6 — начало Заводного города

Новые уровни 5 и 6 добавлены в браузерную демоверсию. Конвейеры передвигают персонажа, паровые подъёмники мягко подбрасывают вверх. После уровня 6 лавка Моки открывает второе улучшение здоровья за 160 монет; первое за 120 монет сохраняется при пропущенной покупке. Итого 6/16 уровней, 18/48 фрагментов и 3/8 мини-боссов. Прежний ориентир 8–12 минут заменён: обычные уровни 6–8 минут, с мини-боссом 8–10 минут. Эти значения ещё не подтверждены ручными прохождениями. Оригинальная внешность Рикиту и Моки не менялась; Switch NRO не существует.

Старое локальное сохранение, в котором игрок победил после уровня 4 в версии v0.5, автоматически переводится на экран перехода к пятому уровню (монеты и купленные сердечки не сбрасываются).

## v0.7 — измерение реального игрового времени

В интерфейсе прототипа появился секундомер активного времени уровня (паузы исключены) и счётчик полученных повреждений. Значения фиксируются вместе с контрольными точками и сохраняются между перезапусками браузера. Старые сохранения без этих полей работают. Эти данные позволяют оценить фактическое время прохождения и пересмотреть маршруты; **целевые 6–8 минут на обычный уровень и 8–10 минут с мини-боссом ещё не подтверждены**. Счётчик не вводит ограничение времени на уровень.

## v0.7 — завершение Заводного города

Добавлены уровни 7 и 8, 9470 и 10180 px соответственно: четыре секции, три контрольные точки, три обязательных фрагмента и 90 монет на каждом. После восьмого уровня четвёртый мини-босс и магазин Моки. Вторая глава не даёт право купить третье сердце: оно откроется после десятого. Старое сохранение с финалом шестого уровня переносится на седьмой. Всего 8/16 уровней и 4/8 мини-боссов. Оригинальные образы героев не затрагивались. Нативной Switch-сборки пока нет.

## Целевое время прохождения (решение от 20.10.2026)

- Обычный уровень: **6–8 минут** при первом стандартном прохождении (три обязательных фрагмента, без поиска всех монет).
- Уровень с мини-боссом: **8–10 минут**, включая бой.
- Полный поиск большинства монет и секретов: ориентировочно **10–15 минут**.
- Уровни не ограничиваются таймером; сохраняются три контрольные точки и доступный уровень сложности. Время активной игры показывает существующий HUD.
- Эти значения — **цели игрового дизайна, а не подтверждённые измерения**. Изменять расположение платформ, исследовательские ответвления и плотность интересных событий после реальных прохождений; не сокращать карту только ради ширины.

## v0.8 — журнал завершённых уровней

После завершения уровня записываем его номер, активное игровое время, полученные попадания и количество найденных монет (из 90). Записи сохраняются **локально в браузере** и переживают перезагрузку и переход к следующему уровню. Последний результат показывается на экране завершения уровня и у Моки; на игру не накладывается ограничение по времени. Старые сохранения без журнала продолжают работать. Показатели в GitHub CI, где игровой персонаж перемещается прямо по координатам, нельзя считать реальными замерами прохождения.

**Важно:** это полный технический сценарный маршрут в браузере, а не завершённая художественная игра и не нативная Switch-сборка. Спрайты утверждённых персонажей, сюжетные кат-сцены, музыка, настоящие исследования игровых маршрутов и полноценный баланс ещё требуют разработки. Целевой темп 6–8/8–10 минут не подтверждён игровыми замерами.
